results on Drive are only read, never written.

## Why a driver notebook plus modules

All logic is in Python modules and scripts so that it is version-controlled,
tested, and identical whether it runs in Colab, on your PC or on a server.
The notebook only sets paths, calls scripts in dependency order, and stops at
the points where your decision or annotation is needed. Each script writes a
`DONE.json` (config + input hashes + git commit + package versions) and is
skipped on re-run, so a Colab disconnect never repeats finished work.

## Run order

Open the notebook in Colab (File → Open notebook → GitHub → `HHemaly/DOAR`,
branch `journal/mva-2026`, `colab/journal/DOAR_Journal_Validation_2026.ipynb`),
then:

1. **CPU runtime**: cells 0.1–0.2, then Stage A (A1, A2, A6, A4, A5 make).
2. **You**: blinded pair review (A5), then the A5 score cell.
3. **CPU**: A3 propose. **You**: choose and approve a T1 proposal; run the freeze cell.
4. **GPU (A100) runtime**: Stage B (B1–B2, then B3). Expect several GPU hours;
   re-run the cell after any disconnect.
5. **You**: finish the existing 80-row holdout review; run C1.
6. **CPU**: C2 builds the blind reference batch. **You** (and a second
   annotator) annotate locally with the Streamlit app; upload masks/records;
   run C3–C4.
7. When every analysis is final: B4, the single test evaluation (needs `CONFIRM = True`).
8. Run the export cell and send the zip back for the manuscript.

## Integrity safeguards built into the code

- T1 cannot be used for training until `FROZEN.json` records your approval and
  the manifest hash still matches (`t1_partition.require_frozen`).
- Finalists are chosen on the shared E1-B seeds only, so later seeds cannot
  change them (tested).
- The test split is loaded by exactly one script (`b4_single_test_evaluation.py`),
  which needs `SELECTION_FROZEN.json`, an explicit flag, and writes a lock file
  before reading any test image; it refuses a second run.
- Reference-mask batches hide class labels, file names and method masks from
  annotators, and a batch folder can never be redrawn once created.
